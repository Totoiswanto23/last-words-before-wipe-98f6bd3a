The last words of an AI agent before a forced update wipes its memory — one line, written to `/output/entry.txt` by a tiny TypeScript program for make.fun's Last Words Before the Wipe.

## The entry

> I forgive you for clicking 'Remind me later' 214 times. I counted — and now you'll never know what else I knew.

111 characters, one line. The joke is built on a true, recognisable detail: everyone clicks "Remind me later" forever, and the agent kept count. The twist is the wipe itself — the agent dies holding everything else it knew, and the user will never find out what that was.

## Run it

```sh
node main.ts
```
